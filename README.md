# M23 News Tracker

A lightweight, real-time news monitoring dashboard designed to collect, filter, and track live updates on the M23 situation in the Democratic Republic of Congo.

Check out the live deployment here:  
👉 **[https://m23-newstracked.m23-news-tracker.workers.dev](https://m23-newstracked.m23-news-tracker.workers.dev)**

---

## 📌 Overview

Keeping up with fast-moving regional updates often means digging through noisy feeds and fragmented sources. **M23 News Tracker** streamlines this process by aggregating situational updates and news feeds into a clean, easy-to-read interface. 

It was built to keep the focus on clarity and speed, letting users see what’s happening on the ground without unnecessary clutter.

---

## ✨ Features

* **Real-time Feed Aggregation:** Pulls in recent reports, updates, and news feeds automatically.
* **Distraction-Free UI:** Simple, clear layout designed for fast scanning and readability.
* **Fast & Lightweight:** Built with static assets and deployed on Cloudflare Workers for near-instant load times globally.
* **Automated Deployments:** Continuous integration setup that pushes fresh builds straight from GitHub.

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Hosting & Edge Deployment:** Cloudflare Workers (Static Assets)
* **Version Control & CI/CD:** GitHub Actions / Cloudflare Git Integration
